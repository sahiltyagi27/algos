```text
graph BFS/DFS -> topological sort -> DP -> greedy -> backtracking
```

## Interview Habit

For each problem:

```text
1. State brute force.
2. Identify the pattern.
3. Explain the visual idea.
4. Walk through a small example.
5. Give time and space complexity.
```
